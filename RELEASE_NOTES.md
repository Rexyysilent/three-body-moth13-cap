# v1.0.0-rc1 release notes

This release candidate freezes the first public-review package for the `(1, 1, 1001/1000)` periodic-orbit certificate.

Included:

- 1,955-dimensional multiple-shooting Krawczyk certificate;
- 244-segment center and full-box C1 interval enclosures;
- conservative squared pair-separation threshold `0.003`;
- quick archived-enclosure verifier and complete regeneration path;
- technical report, catalog audit, machine-readable candidate, and orbit visualization;
- GitHub CI, container recipe, checksums, and independent-verification protocol.
- Apache-2.0 code and CC-BY-4.0 documentation/data licensing;
- `Rexyysilent` creator and public repository metadata.

Known limitations:

- minimal-period primitivity and the Moth-I^13 itinerary are not interval-certified;
- the local mass continuation is not quantified over an explicit interval;
- novelty is conditional on the surveyed accessible catalogs;
- an external Level 2 regeneration has not yet been reported;
- the final Zenodo DOI will be assigned only after external review and `v1.0.0`.
